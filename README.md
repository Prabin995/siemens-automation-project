# Industrial Automation Project - Siemens TIA Portal

## 📋 Overview
This repository contains a finalized Siemens PLC automation project developed using TIA Portal. It includes the complete project archive for deployment and backup purposes.

---

## 📂 Repository Structure
* `archives/` - Contains the compressed TIA Portal project archive (`.zap` file).
* `docs/` - Contains related engineering documents, I/O lists, or schematics (if applicable).

---

## 🚀 How to Open the Project
1. Download or clone this repository to your local machine.
2. Go to the `archives/` folder and retrieve the `.zap` project file.
3. Open **TIA Portal**, go to **Project > Retrieve**, and select the archive file to load the project onto your engineering station.
